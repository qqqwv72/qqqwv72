## 📌 Featured

### [mini-editor](https://github.com/qqqwv72/mini-editor) — tiny native code editor

Rust + egui in a single ~4 MB binary with zero runtime deps: tiling bspwm-style UI, drop-a-picture auto-theming, fuzzy finder, Rofi complete and grep, background cargo checks, virtual view for 100k-line files.

⬇️ [Latest release](https://github.com/qqqwv72/mini-editor/releases/latest)
