## 📌 Featured

### [mini-editor](https://github.com/qqqwv72/mini-editor) — tiny native code editor
Rust + egui, single ~4 MB binary, zero runtime deps. Tiling bspwm-style UI, drop-a-picture auto-theming (k-means), fuzzy finder, Rofi complete + grep, background `cargo check`, virtual view for 100k-line files.

⬇️ [Latest release](https://github.com/qqqwv72/mini-editor/releases/latest)
